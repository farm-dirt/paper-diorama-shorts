# Travel demo: Frost Bamboo Pudding (24 Nov 2026)
The model for how every paper-diorama short now works: a no-voice first-person JOURNEY told by a map
(home → frozen river → glowing woods → map tick → icicle cave → frost wall → crack, snap, scoop, bite → tick → loop),
motivated transitions (dive / fog / gust / whip / dark), a walking camera, POV mittens, and brand-new foley.
Copy into a project's project-files/, run `python3 make_project.py`, then foley.py → audio.py → build_preview.py.
